# Blackjack

A simple command-line Blackjack game in Python.

## How to play

```bash
python blackjack.py
```

- Hit `h` to draw a card
- Hit `s` to stand
- Dealer hits on 16 and below, stands on 17+
- Aces count as 11, reduced to 1 if needed to avoid busting

## Rules

- Standard single-deck
- No splitting, doubling down, or insurance (yet)
